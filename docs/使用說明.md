# 使用說明

## 快速開始

1. 點選「選擇圖片資料夾」。
2. 在「① Logo」新增或選擇 Logo，設定九宮格位置。
3. 在「② 微調」調整大小、邊距、不透明度，也可直接拖曳 Logo。
4. 在「③ 輸出」設定名稱、格式與輸出資料夾，開始批次輸出。

## 單張例外

選取圖片後，勾選「目前這張使用單張例外設定」。

可使用四個快速操作：

- 儲存單張
- 還原整批
- 複製設定
- 貼到選取圖片

## 專案保存

使用「儲存專案」保存目前圖片資料夾、Logo、輸出設定與單張例外；下次可使用「開啟專案」繼續工作。

## 重要說明

- 輸出不會覆蓋原始圖片。
- 圖片全程在本機處理，不會上傳伺服器。
- 本工具免費公開使用，不需要通行碼。
